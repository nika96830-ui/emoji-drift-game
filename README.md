# Emoji Drift: System Dash

A mobile-friendly HTML5 arcade game built with Phaser 3.90.0.

## Play

https://emoji-drift-system-dash-zangui.vercel.app

## Features

- Three stages in one continuous run: Messaging Hub, Gallery & Media Cache, System Core
- Emoji emotional states with different physics/actions
- Keyboard and touchscreen controls
- English and Azerbaijani interface
- Local high score storage

## Run locally

Serve this directory using any static HTTP server, then open `index.html` (e.g. `python3 -m http.server 8000`). Internet access is required for Phaser CDN.

## Deploy

Static website. Set framework to **Other**, root to `/`, and leave build/output commands unset in Vercel. To enable automatic deployment, connect this repository to the existing Vercel project `emoji-drift-system-dash`.

## Current status

Playable source prototype, not yet verified on a physical iPhone. Review gameplay, music/audio permissions and responsive layout before broader public promotion.
